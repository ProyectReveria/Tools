# Welcome to My MuseScore Studio Presets!

First of all, if you want to, you can inspect the files using an XML reader or C. I don't recommend doing so unless you know what you're doing, but it is possible.

The most important thing to know is that these presets are designed for **Ozone 11 Equalizer**, which is available for free and is commonly used in music production.

You can find it here:  
https://www.izotope.com/products/ozone-eq

You can also access it through Native Access.

These presets are designed for **violin, viola, violoncello, and double bass**. The viola preset is based on the violin preset, so you can use the violin preset for viola as well.

**Enjoy!**

Please remember that these presets may not work perfectly in every situation. Different playback systems and audio setups can produce different results, even when using the same equalization settings.

## Note on Equalization

These equalization settings were created manually, using my understanding of the instruments' frequency content and how it can be represented through the **Fourier Transform**.

For those who are unfamiliar with advanced calculus or computational mathematics, the Fourier Transform is one of the ways we represent and analyze sound in computing.

If you would like to learn more, you can check out this interactive guide:  
https://betterexplained.com/articles/an-interactive-guide-to-the-fourier-transform/

For obvious reasons, I do not recommend trying to calculate the Fourier Transform by hand. Take it from someone with experience! 

Also, Ozone performs this kind of processing automatically, without requiring you to understand or calculate the Fourier Transform yourself.
